# CSE440 NLP Project

A simple notebook setup using **UV**.

## How to use:

1. Open `cse440_project.ipynb` in VS Code, Cursor, or Jupyter.
2. In the top right corner of the notebook, select the Python kernel:
   - **`Python 3.13 (CSE440 NLP - uv)`** (or point directly to `.venv/bin/python`).
3. You're all set! You can write and run all your code inside the notebook.

### Optional commands:
- **Add a new library**: `uv add <package_name>`
- **Launch JupyterLab**: `uv run jupyter lab`
